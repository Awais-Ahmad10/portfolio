Machine Learning · Internship

Content Opportunity Scoring

FlyRank ML internship (Applied Search Intelligence track). Given search-console-style data for client sites, the task: rank pages by where content action will pay off — without leaking the answer into the features.

Baseline (rule-based): precision@20 of 0.700 vs a 0.542 base rate, using only non-leaking signals.
Model comparison: Random Forest reached precision@20 0.950 (ROC-AUC 0.737); Logistic Regression was near-random globally (ROC-AUC 0.517) — an honest limit, kept in the write-up.
Leakage checks: trend columns excluded (they define the label); a 90-day/30-day window-overlap issue caught and fixed in audit.
